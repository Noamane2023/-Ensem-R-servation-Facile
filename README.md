# Ensem Réservation Facile

## Description

**Ensem Réservation Facile** est une extension Chrome conçue pour simplifier la réservation des repas à l'École Nationale Supérieure d'Électricité et de Mécanique (ENSEM).  
Elle vous permet de sélectionner rapidement vos options de repas (petit déjeuner, déjeuner, dîner) avec une interface claire et intuitive.

---

## Fonctionnalités

- Réservation facile des repas : petit déjeuner, déjeuner et dîner.
- Options pour manger sur place ou à emporter.
- Possibilité d'annuler une réservation en un clic.
- Sauvegarde locale de vos préférences pour une meilleure expérience.

---

## Installation

1. Téléchargez ou clonez ce dépôt.
2. Ouvrez Google Chrome et rendez-vous dans `chrome://extensions/`.
3. Activez le **Mode développeur** en haut à droite.
4. Cliquez sur **Charger l’extension non empaquetée**.
5. Sélectionnez le dossier de l’extension.
6. L’extension apparaît alors dans la barre d’outils de Chrome.

---

## Utilisation

- Cliquez sur l’icône de l’extension.
- Choisissez les repas que vous souhaitez réserver via les boutons.
- Vos choix sont enregistrés localement.
- Vous pouvez annuler ou modifier vos réservations facilement.
